# Звуки из файлов

Положите сюда mp3-файлы с открытой лицензией — приложение само их найдёт и покажет в настройках:

| Файл | Где используется |
|---|---|
| `lofi.mp3` | Фон во время работы: «Lo-fi музыка» |
| `fireplace.mp3` | Фон во время работы: «Камин» |
| `dance.mp3` | Музыка на отдыхе: «Танцевальная музыка» |

Файлы проигрываются по кругу, поэтому лучше брать треки, у которых конец плавно переходит в начало.
Дождь, белый и мягкий шум, весёлая мелодия, свист и сигналы синтезируются в коде — файлы для них не нужны.
Если файл добавлен, поднимите версию `VERSION` в `sw.js`, чтобы установленное приложение обновилось.
