# Помидорки — таймер Помодоро для детей

Таймер Помодоро для детей с СДВГ и СДВГ+аутизмом. Работает в браузере на телефоне и планшете (Android и iOS), устанавливается на главный экран как приложение и после первого открытия работает без интернета.

## Как это работает

| Помидорка | Работа | Отдых | Каждый 4-й отдых |
|---|---|---|---|
| Черри | 10 мин | 2 мин | 4 мин |
| Сливка | 15 мин | 3 мин | 6 мин |
| Солнышко | 20 мин | 4 мин | 8 мин |
| Бычье сердце | 25 мин | 5 мин | 10 мин |

1. Ребёнок выбирает помидорку под свои силы на сегодня и жмёт «Начать!».
2. **Работа.** Помидорка пишет в тетради, листает книгу, задумчиво чешет голову. Фоном может звучать дождь, белый или мягкий шум.
3. **Время вышло.** Отдых не начинается сам: появляется большая зелёная кнопка «Готов отдохнуть?», чтобы ребёнок мог закончить мысль. Кнопка ждёт столько, сколько нужно.
4. **Отдых.** Помидорка пританцовывает, по очереди поднимает руки, валяется и насвистывает. Может играть весёлая мелодия.
5. **Отсчёт 10…0** и надпись «А теперь за работу!». На крайний случай есть кнопка «Ещё минутку» (2 раза за перерыв). Работа начинается автоматически.
6. **«Готово!»** внизу экрана. Ребёнок подтверждает «Вся работа сделана?» и получает награду:
   - до 3 помидорок — «Как молния!»
   - 4–7 — «Сильный характер!»
   - 8 и больше — «Марафонец!»
7. **«Награды»**: календарь по дням (у значка стоит число, если награда за день получена несколько раз) и общие счётчики.

Пауза есть во время работы и отдыха. Данные хранятся только на устройстве.

## Настройки

- Язык: русский / English.
- Звуки: фон во время работы, музыка на отдыхе, свист, сигналы, тиканье при отсчёте, громкость.
- Спокойный режим: анимация «Обычная / Мягкая / Без движения», вибрация.
- «Не гасить экран», пока идёт таймер.

## Запуск

Сборка не нужна, это обычные HTML/CSS/JS-файлы.

Локально (из папки проекта):

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

**Публикация на GitHub Pages:** Settings → Pages → Source: «Deploy from a branch» → Branch: `main`, папка `/ (root)` → Save. Через минуту приложение будет доступно по адресу `https://<логин>.github.io/PomodorroKids/`. Эту ссылку открываем на телефоне и добавляем на главный экран.

## Что где лежит

```
index.html               разметка экранов
css/app.css              палитра, шрифты, анимации
js/app.js                логика таймера и экранов
js/i18n.js               все тексты на русском и английском
js/store.js              режимы, правила наград, хранение данных
js/audio.js              синтез звуков (дождь, шумы, мелодия, свист, сигналы)
js/icons.js              иконки и значки наград
assets/characters/       персонажи: 4 сорта × 7 поз
assets/fonts/            шрифты (Nunito, Onest, Unbounded, Good Vibes Pro)
assets/audio/            сюда класть mp3: lofi, камин, танцевальная музыка
sw.js                    офлайн-режим
tools/cut_characters.py  нарезка листов с персонажами на позы
```

Позы персонажей: `wave` (машет), `write` (пишет), `read` (листает), `think` (думает), `dance` (танцует), `relax` (отдыхает и свистит), `jump` (прыгает от радости).

**После любых изменений** поднимите `VERSION` в `sw.js` (например, `v1` → `v2`), иначе установленное приложение может показывать старую версию.

## Палитра и шрифты

Сливочный `#FFF8EE` (фон), томатный `#F45B45` (главные кнопки), солнечный `#F5C84B` (награды), розовый `#E98B91`, листовой `#568B4D` (отдых и успех), черничный `#263B59` (текст и контуры, как оправа очков), мятный `#E8F1E5`.

Шрифты: Nunito ExtraBold для заголовков, Onest для текста, Unbounded для цифр таймера, Good Vibes Pro для коротких восклицаний («Привет!», «Ура!»).
